## Tiêu chí nghiệm thu và tests

- Migrations áp dụng được lên DB test mới; schema/FK/check/unique/index/trigger đúng thiết kế, finite numeric và ownership ngăn input sai.
- Auth profile trigger chạy, grants/RLS kiểm SELECT và deny direct DML cho A/B/anon; inspect RPC owner/search_path/default EXECUTE, private schema không expose.
- Owner A không ghép item vào meal/scan B hoặc profile/portion sai; invalid item rollback meal/items/receipt.
- Snapshot, grams-only edit, profile selection, partial nutrition, timezone/DST/day boundary và optimistic revision được test.
- Idempotency create/patch/delete same payload và concurrent requests không duplicate; changed payload conflict; replay trước revision/existence, invalid request không để success receipt.
- Storage integration: A đọc/sign URL object A, B/anon bị chặn; direct upload/update/delete user bị chặn; server upload path owner đúng. Không chỉ test policy text trong pgTAP.
- Scan predicted JSON chỉ server role ghi; user confirmation không sửa predicted fields. Model readiness/inference chưa thuộc DB test.
- Commands + exit codes, CLI/runtime versions, test counts/failures, reset provenance nếu có và phần còn thiếu ghi trong review. Không báo tests passed khi Docker/stack chưa chạy.
