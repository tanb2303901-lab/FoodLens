- Cấu hình được validate, không log secrets. Local JSON trong ignored data/processed; runtime chỉ cần public API key và cấu hình signing (HS256 local secret hoặc ES256/RS256 JWKS). Không dùng service-role key cho user requests/readiness.
- JWT verify signature, fixed algorithm allowlist/issuer/audience/expiry, required claims và UUID subject; authenticated role, không nhận anon/service token. Asymmetric JWKS có cache/rotation; không dùng jku/url do token cung cấp. Secrets không có trong errors/logs.
- Supabase HTTP Authorization gắn mỗi request, không mutate shared client headers. Owner chỉ từ verified sub. DB/RLS vẫn thực thi bằng user JWT.
- Readiness qua RPC boolean không tham số, quyền read cố định, không tiết lộ catalog/private data. Liveness độc lập DB; DB lỗi trả 503 readiness, model chưa ready vẫn cho core ready nhưng scan=false.
- Catalog active, search/pagination cursor gắn filter/order và HMAC chống sửa; limit 1..100, field/query không hợp lệ 422, unknown/inactive UUID 404. Payload DTO không lộ raw metadata/reference candidates.
