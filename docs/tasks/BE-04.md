## Tiêu chí nghiệm thu

1. OpenAPI 3.1 hợp lệ, khớp runtime về paths/operations/auth/schema/headers. Samples hợp lệ theo schema, thiếu nutrition là NULL; không có fake detections/calories hoặc tokens/signed URLs.
2. Hướng dẫn mô tả login/refresh qua Supabase Auth, user bearer token, pagination/timezone, idempotency/ETag và lỗi có request_id; đủ để frontend triển khai luồng thủ công.
3. Chạy acceptance Python/data/contract, SQL và HTTP liên quan trên dedicated local stack; cleanup chỉ fixtures của test, giữ catalog/import baseline. Không chạy DB-02 empty-catalog HTTP suite trên DB đã import.
4. Phân biệt backend core đạt với model chưa ready, nutrition chưa approved, device/frontend chưa kiểm thử và giới hạn reconciliation DB/Storage.
5. Có tài liệu bàn giao và task frontend sẵn để chủ dự án chuyển; ghi đúng chưa gửi/thi công frontend.
